GaugeKing support center

Use this page as the official support endpoint for app stores, users, and support emails. It includes quick fixes, setup guidance, and escalation details.

Contact support

Email: support@pocketaimechanic.com

Include your device model, iOS version, vehicle profile, OBD adapter type, and screenshots of the dashboard when possible.

Before contacting us

  1. Confirm Bluetooth and permissions are enabled for the app.
  2. Power-cycle the OBD adapter and retry connection.
  3. Verify the selected vehicle profile matches your setup.
  4. If using Demo/Test Mode, confirm expected scenario and manual overrides.

Common troubleshooting

Adapter not connecting

  • Check ignition state and adapter power LED.
  • Ensure the adapter is not already paired to another app.
  • Retry scan from the Adapter screen after a full disconnect.

No RPM or gauge values

  • Some values depend on PID support from your vehicle ECU.
  • Use Generic profile first, then compare with model-specific profiles.
  • Enable Test Mode to validate UI behavior independent of vehicle data.

Layout or gauge visibility issues

  • Open Edit Layout and confirm gauges are in the Now Showing section.
  • Use reorder controls to move gauges to preferred positions.
  • Save layout changes before leaving the editor.

Feature support notes

These notes explain advanced behavior that users commonly ask about.

Synthetic Power and Torque

GaugeKing can calculate synthetic values when direct ECU data is missing. Source labels indicate whether values are measured, derived, or estimated.

Shift Light Modes

F1/GT3 and Tach Colour shift light widgets follow your configured thresholds, warning zone percent, and optional per-gear shift points.

Demo/Test Mode

Demo scenarios are intended for safe previewing and validation. They should not be interpreted as live vehicle measurements.
